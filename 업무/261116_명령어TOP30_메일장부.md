## 4. 메일 라벨 → 장부 → 주간 점검 (/메일장부 · /구독점검)

Gmail에 전용 라벨을 만들어 **그 라벨만** Claude가 읽게 하고(전체 메일함 X), 장부로 정리한 뒤 매주 점검 리포트를 받는 방식입니다.

| 명령 | 라벨(예) | 대상 메일 | 장부 열 | 상태 |
|---|---|---|---|---|
| /메일장부 | `안전공문` | 고용노동부·안전보건공단·발주처·검사기관·교육기관·소방서 공문·통보·안내 | 발신기관 / 수신일 / 제목 / 구분(점검·검사·교육·제출·회신·과태료) / 기한 / 담당 / 메시지 ID / 상태 / 메모 | 완료 · 진행 · 기한임박(D-7) · 기한초과 |
| /구독점검 | `Receipts` | AI 도구·SaaS 결제 영수증·인보이스 | 서비스 / 결제일 / 금액 / 결제 주기 / 메시지 ID / 상태 / 메모 | 유지 · 검토 · 일시중지 · 해지 |

### 진행 7단계
1. **라벨 만들기** — 발신자·키워드 필터로 메일을 자동 분류 (Claude가 만들 때는 먼저 확인)
2. **Gmail 연결** — 커넥터 연결 후 `label:안전공문` 안에서만 검색
3. **장부 만들기** — 메시지 ID로 같은 메일을 두 번 넣지 않음. 기한·금액은 메일 원문 그대로, 없으면 「확인 필요」
4. **상태 표시** — 행마다 상태를 고르고 메모에 판단 근거를 적음
5. **주간 점검 예약** — 매주 최근 8일 메일 검색 → 새 항목 추가 → 기한임박·기한초과 / 가격 인상·중복·해지 후 결제 표시
6. **주간 리포트** — 새 공문 수, 7일 안 기한, 기한초과, 회신 필요 / 월 구독 총액, 가격 인상, 중복 가능성
7. **결정은 사람이** — 회신·제출·해지는 사용자가 결정, 실행 전 확인

> 공문 장부에 회사명·현장명이 들어가면 구글 드라이브(비공개) `09_사업장별_자료`에만 둡니다. 이 저장소에는 양식만 올립니다.
