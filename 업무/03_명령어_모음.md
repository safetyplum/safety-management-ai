# 업무 명령어 모음 (복사해서 사용)

> 어느 AI에서나 그대로 붙여 넣어 쓸 수 있습니다. [ ] 안만 바꾸세요.

## 법령
```
산안법 직원으로, [작업/상황]에 적용되는 법 조문을 표로 정리해줘.
의무/권고 구분, 근거 조문, 위반 시 벌칙, 확인 필요 사항 포함.
```

## 위험성평가
```
위험성평가 직원으로, [제조업/건설업] [작업명] 위험성평가표 만들어줘.
작업단계-유해위험요인-현재대책-빈도-강도-위험도-감소대책-개선후 위험도 순서.
```

## JSA
```
위험성평가 직원으로, [작업명]을 5~8단계로 나눠 JSA 작성해줘.
단계별 위험요인 2개 이상, 대책은 제거→대체→공학→관리→보호구 순서.
```

## TBM
```
위험성평가 직원으로, 오늘 [작업명] TBM 내용 만들어줘.
핵심 위험 3가지, 대책, 근로자 확인 질문 3개, 5분 분량.
```

## 유해위험방지계획서
```
계획서 직원으로, [설비/공사 개요]가 유해위험방지계획서 제출대상인지 판별해줘.
근거 조문, 기준값 비교표, 제출 서류 목록, 제출 기한.
```

## 중처법
```
중처법 직원으로, 상반기 안전보건관리체계 이행점검표 만들어줘.
시행령 제4조 각 호별 점검항목-증빙서류-미흡사항-개선조치.
```

## 엑셀
```
엑셀 직원으로, [점검표/대장 이름] 엑셀 만들어줘.
입력 시트와 집계 시트 분리, 드롭다운, 기한 초과 자동 표시, A4 인쇄.
```

## 문서검토
```
문서검토 직원으로, 첨부 문서의 법조항·날짜·수치·고유명사 오류를 표로 찾아줘.
원래 값은 고치지 말고 위치-현재-문제-수정안-근거-중요도로 표시.
```

## 감독 대비
```
문서검토 직원으로, 근로감독관 입장에서 첨부 문서의 약점 10가지를 찾아줘.
반려·지적 가능성 높은 순서로.
```
