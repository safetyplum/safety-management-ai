# Claude 코워크 60분 설정 — 1인 안전관리자용

> 참고: Abkr Sadiq 「Set Up Claude Cowork in 60 Minutes」 인포그래픽 번역 + 이 저장소 기준 점검.
> **일보다 시스템을 먼저 만든다.** 프롬프트를 반복하지 말고, 작업 흐름을 만든다.

## 60분 시간표

| 시간 | 할 일 | 내 상태 |
|---|---|---|
| 5분 | 첫 작업 시작 | 완료 |
| 15분 | 컨텍스트 파일 만들기 | 완료 — [CLAUDE.md](../CLAUDE.md), [공통원칙](../AI직원/00_공통원칙.md) |
| 10분 | 코워크 프로젝트 설정 | **보완 필요** (아래 4단계) |
| 10분 | 폴더 정리 | 완료 — 드라이브 01~09 폴더 |
| 10분 | 전체 지침 설정 | 완료 — 파일명 `YYMMDD_내용_구분`, 원본 보존 |
| 10분 | 도구 연결·일정 설정 | 완료 — 드라이브·Gmail·GitHub 연결, 매주 자동 업그레이드 |

## 단계별 내용

| 단계 | 원문 | 안전관리 실무 적용 |
|---|---|---|
| 1 작업 하나로 시작 | 원하는 결과 설명 / 실행 전 확인 질문 / 첫 결과 검토 후 다듬기 | `/질문5`로 업종·규모·제출처를 먼저 확인하게 함 |
| 2 재사용할 컨텍스트 | about-me.md(역할·담당) / working-style.md(말투·선호·기준) / 참고 파일은 명확하게 | 내소개·내문체·작업규칙 파일(드라이브 00_Claude_기본설정) |
| 3 연결·자동화 | 쓰는 도구만 연결 / 관련 연동 추가 / 반복 작업 예약 | 드라이브·Gmail·GitHub, 매주 월요일 자동 업그레이드, 매월 월간 보고 |
| 4 프로젝트 공간 | 반복 업무마다 프로젝트 / 프로젝트별 지침 / 고객 업무와 주간 보고 분리 | 사업장별 위험성평가, 월간 교육, 주간 보고를 프로젝트로 분리 (사업장 자료는 비공개) |
| 5 작업 공간 정리 | ABOUT ME / PROJECTS / TEMPLATES / OUTPUTS | 00_기본설정 / 09_사업장별_자료 / [서식집](../서식집/README.md) / 01~08 업무 폴더 |
| 7 전체 규칙 | 폴더·파일 규칙 / 이름 규칙 / 먼저 읽을 파일 지정 | CLAUDE.md → 공통원칙 → 해당 직원 지침 순서로 읽음 |

※ 원본 인포그래픽에 6번 단계 없음. "Coment tools"는 "Connect tools(도구 연결)"의 오타로 보임.
