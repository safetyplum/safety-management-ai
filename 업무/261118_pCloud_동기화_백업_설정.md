# pCloud Desktop 동기화·백업 설정 (안전 자료용)

> 원본: pCloud Desktop 동기화 설정 가이드(2026.11.14 PDF)를 1인 안전관리자 자료 관리 방식에 맞게 고친 것입니다.
> 메뉴 이름은 pCloud 앱 버전에 따라 다를 수 있습니다 — 「확인 필요」 표시 부분은 설치 후 화면과 대조하세요.

## 결론 먼저

| 질문 | 답 |
|---|---|
| Sync와 Backup 중 무엇을? | 안전 자료 **백업 목적이면 Backup(일방향)** — PC에서 지워도 pCloud에 남음 |
| 어떤 폴더를? | `01_중대재해처벌법` ~ `08_파이썬 공부` (회사명 없는 일반 자료) |
| 올리면 안 되는 폴더 | **`09_사업장별_자료`** — 회사명·현장명 자료는 구글 드라이브(비공개)에만 (CLAUDE.md §10) |
| Sync는 언제? | 여러 기기에서 같은 파일을 자주 고칠 때만. 삭제가 양쪽에 반영되므로 원본 보관함으로 쓰지 않음 |

## 1. Sync vs Backup

| 기능 | 동작 | PC에서 삭제하면 | 안전 자료 추천 |
|---|---|---|---|
| **Sync** (동기화) | PC 폴더 ↔ pCloud 폴더 양방향 실시간 맞춤 | pCloud에서도 **삭제됨** | 작업 중인 폴더만, 신중히 |
| **Backup** (백업) | PC → pCloud 일방향 복사 | pCloud에는 **남음** | ✅ 드라이브 자료 보관용 |

> 원본 가이드는 「대부분 Sync」를 권하지만, 원본 보존 원칙(고친 파일은 `_vYYYYMMDD`로 새로 저장)에는 Backup이 맞습니다.

## 2. 설치·로그인
1. 공식 사이트에서 pCloud Drive 내려받기 → https://www.pcloud.com/download-free-online-cloud-file-storage
2. 설치 후 **모바일 앱과 같은 계정**으로 로그인
3. 탐색기에 pCloud Drive(보통 `P:`)가 생기면 완료

## 3. 백업할 폴더 준비 (PC)

| 원본 위치 | 내용 | pCloud 백업 |
|---|---|---|
| `D:\안전폴더` (PC 작업 폴더) | 내려받은 자료, 작업 파일 | ✅ (단, `09_사업장별_자료` 제외) |
| Google Drive 데스크톱 폴더 `01`~`08` | 드라이브 업무 자료 | ✅ — 드라이브 앱을 **미러링(파일을 PC에 저장)** 방식으로 둬야 백업 가능 「확인 필요」 |
| Google Drive `09_사업장별_자료` | 회사명·현장명 자료 | ❌ 백업 대상에서 **반드시 제외** |

> PC 작업 폴더 이름은 `D:\안전폴더` 기준입니다(이전 이름 `D:\안전젝터폴더`). 실제 경로를 확인하세요.

## 4. 설정 방법

### 방법 A — 앱에서 설정 (추천)
1. 작업 표시줄 pCloud 아이콘 더블클릭(또는 우클릭 → Open pCloud Drive)
2. 왼쪽 메뉴에서 **Backup** 선택 (작업 폴더를 양방향으로 맞출 때만 **Sync**)
3. 폴더 추가 → `01_중대재해처벌법` ~ `08_파이썬 공부`를 **하나씩** 선택 (상위 폴더 통째로 선택 금지 — `09`가 딸려 들어감)
4. pCloud 쪽 저장 위치: `안전자료_백업/` 폴더를 새로 만들어 지정
5. 추가(Add) 클릭

### 방법 B — 폴더 우클릭 (Sync만)
1. 동기화할 폴더 우클릭 → **Sync to pCloud**
2. pCloud 안 위치 지정 후 확인
> `09_사업장별_자료` 폴더나 그 상위 폴더에서는 사용하지 않습니다.

## 5. 상태 확인·관리
- 트레이 아이콘 클릭 → 진행 상황(속도·남은 시간)
- Backup/Sync 탭에서 설정된 폴더 목록 확인, 필요하면 **Stop**으로 해제
- 해제해도 이미 올라간 파일은 남음(삭제되지 않음)

## 6. 주의사항 체크리스트

| 확인 | 항목 |
|---|---|
| □ | 백업 폴더 목록에 `09_사업장별_자료`가 **없다** |
| □ | 파일명·내용에 회사명이 든 자료가 01~08 폴더에 섞여 있지 않다 (섞여 있으면 09로 옮긴 뒤 백업) |
| □ | Sync로 걸린 폴더에서는 파일을 지우기 전에 한 번 더 확인한다 (pCloud에서도 지워짐) |
| □ | 처음 백업은 용량이 크므로 Wi-Fi·퇴근 후 시간에 실행 |
| □ | pCloud 공유 링크(Public link)는 만들지 않는다 |
| □ | 모바일 앱에서 같은 계정으로 백업 파일이 보이는지 확인 |

## 7. 전체 보관 체계 (현재 기준)

| 저장소 | 역할 | 회사명 자료 |
|---|---|---|
| Google Drive | 원본·최신본 (01~09 폴더) | ✅ 여기만 |
| pCloud | 01~08 백업 사본 | ❌ |
| Dropbox | 5MB 초과 큰 파일 보관·백업 | ❌ |
| GitHub(이 저장소, 공개) | 지침·원고·양식·코드 | ❌ (○○ 표기 양식만) |
