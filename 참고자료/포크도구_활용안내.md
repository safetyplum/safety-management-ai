|---|---|

## 5. korean-law-mcp — 법제처 법령을 Claude에 직접 연결 ⭐ 추천

| 항목 | 내용 |
|---|---|
| 기능 | 법령 검색·조문 전문·별표/서식 조회, 판례·결정·해석 검색, 인용 검증(조문이 실제 있는지·현행인지), 조례 상위법 개정 확인 |
| 도구 | legal_research · legal_analysis · search_law · get_law_text · get_annexes · ordinance_radar · search_decisions · get_decision_text · discover_tools · execute_tool |
| 라이선스 | MIT (원본: chrisryugj/korean-law-mcp → 포크: suhyeon123-oss/korean-law-mcp). 원본 업데이트는 포크 화면 **Sync fork** |
| 업무 연결 | 산안법·중처법 직원이 조문을 인용할 때 원문 대조, 문서검토 직원의 「법조항·시행일 오류」 점검, /LATEST·/FACT-CHECK |
| 주의 | 원격 서버(mcp.gomdori.app)는 개발자가 운영하는 외부 서버 — 법령 검색어만 보내고 **회사명·현장명·개인정보는 넣지 않는다**. 최종 근거는 국가법령정보센터 원문 |

### Claude 연결 순서
1. **법제처 API 키(OC) 발급** — 국가법령정보 공동활용 [open.law.go.kr](https://open.law.go.kr/LSO/openApi/guideResult.do) 회원가입 → Open API 신청(무료). 받은 OC 값(보통 아이디)을 메모
2. **claude.ai(PC 웹)** → 설정 → 커넥터 → 「사용자 지정 커넥터 추가」
   - 이름: `한국법령`
   - URL: `https://mcp.gomdori.app/law?oc=발급받은OC`
3. 추가 후 「연결」 → 대화에서 "산안법 제36조 원문 확인해줘"로 시험
4. 휴대폰 앱은 웹에서 추가한 커넥터가 같이 보임
5. (선택) Claude Desktop·Claude Code: `npx --ignore-scripts --omit=optional korean-law-mcp setup` 실행 후 안내대로 OC 입력 — Node.js 18 이상 필요

> OC 키가 URL에 들어가므로 커넥터 주소를 남에게 보내거나 공개 저장소에 적지 않는다.
