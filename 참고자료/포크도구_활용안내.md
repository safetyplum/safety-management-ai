## 1. sanan-search — 산안법 검색기 ⭐ 바로 사용

| 항목 | 내용 |
|---|---|
| 기능 | 산업안전보건법·중대재해처벌법과 시행령·시행규칙·안전보건규칙, 고용노동부 산업안전 고시·지침·예규·훈령 통합 검색 |
| 재해사례 | 제조업·건설업·조선업·서비스업·공공기관 분류 사례 데이터 포함 (cases.json) |
| 데이터 | 국가법령정보센터 공개 데이터, 최근 갱신 2026-11-14 (10.27 개정 산안법 반영 흔적 있음 — 조문별 반영 여부 확인 필요) |
| 쓰는 법 | ① 포크 저장소 → Code → Download ZIP → `index.html` 열기 ② 또는 저장소 Settings → Pages 켜면 휴대폰에서 주소로 접속 |
| 업무 연결 | 산안법 직원·문서검토 직원이 조문 확인할 때, 감독 대비 점검표의 근거 조문 대조 |
| 주의 | 법적 효력은 국가법령정보센터 원문 기준. 라이선스 파일 없음 → 재배포 시 확인 필요 |

## 3. daiso-shms — 안전보건관리체계 이행관리 시스템

| 항목 | 내용 |
|---|---|
| 기능 | 중처법 의무별 이행 현황 작성, 산안법 의무 19개 점검, ISO 45001 심사 대응 매트릭스, 매뉴얼→절차서→지침서→양식 46개 문서 개정이력, 반기 점검·개선조치(CAPA)·증빙 자료함·선임 현황 |
| 구성 | 정적 웹(GitHub Pages) + Supabase(선택). 설정 없이도 로컬 저장 모드로 사용 가능 |
| 쓰는 법 | PC에서 폴더 안에서 `python -m http.server 8899` → 브라우저 `localhost:8899` (파일 더블클릭으로는 안 열림) |
| 업무 연결 | 중처법 직원의 반기 이행점검 구조 참고, [서식집](../서식집/README.md) B04·B13~B16과 비교. 제조·건설 사업장용 조항 목록으로 바꿔 쓰는 것도 가능 |
| 주의 | **특정 회사(유통·물류) 기준**이라 제조·건설 의무 조항은 직접 보완해야 함. 저장소 안에 원 회사 내부 인수인계 문서가 포함돼 있어 그대로 공개 재배포 금지. 라이선스 파일 없음 → 확인 필요 |

## 4. JSA-generator — 위험성평가 자동 생성 API

| 항목 | 내용 |
|---|---|
| 기능 | 작업명·장소·공구 입력 → AI(Gemini)가 위험성평가 항목 생성 (웹사이트 연동용 서버) |
| 쓰는 법 | 서버 배포 + Gemini API 키 필요 → 1인 안전관리자가 직접 운영하기엔 부담 |
| 업무 연결 | 같은 기능은 [위험성평가 직원](../AI직원/03_위험성평가직원.md) + [명령어 모음](../업무/03_명령어_모음.md)으로 대체 가능 |
| 주의 | 법령 근거 검수 기능 없음 → 결과는 반드시 검토. 라이선스 파일 없음 |
