# 감독 대비 안전서류 관리 — 제조업

> 원본 엑셀: [261104_감독대비_안전서류관리_제조업.xlsx](261104_감독대비_안전서류관리_제조업.xlsx) (작성 2026.11.4, 13개 시트)
> 법령 기준: 산안법(2026.6.1 시행 개정 포함)·시행령 별표35·중처법. 과태료·조문은 사용 전 법제처 원문 대조 — **확인 필요**

## 엑셀 사용법
1. `0_안내` 시트에 사업장 정보 입력
2. `2_서류점검표` O열에 상태(완비/보완필요/미비/해당없음) 입력
3. `1_대시보드`에서 준비율·미비 건수·예상 과태료 자동 확인

## 시트 구성

| 시트 | 내용 | 주로 쓰는 때 |
|---|---|---|
| 1_대시보드 | 준비율·미비 건수·예상 1차 과태료(감경 반영)·기한 경과 자동 집계 | 주간·월간 보고 |
| 2_서류점검표 | 법정 서류·의무 제조업 전체 목록 — 근거·주기·보존·감독 포인트·과태료, 상태 입력 시 리스크 자동 | 연초 점검, 감독 통보 즉시 |
| 3_연간달력 | 법정 주기 업무 월별 달력(기준월 입력 → 자동 표시) | 연간 계획 |
| 4_감독지적포인트 | 근로감독·공단 점검에서 자주 지적되는 사항과 사전 예방·증빙 | 점검 전 셀프 확인 |
| 5_관리감독자 | 시행령 제15조 업무 7가지·별표3 작업시작 전 점검·명부(교육 16시간) | 관리감독자 지정·평가 |
| 6_도급관리 | 도급인·수급인 의무, 협의체·순회·합동점검 주기, 체크리스트, 2026~27 개정 | 협력업체 관리 |
| 7_교육관리 | 교육 종류별 시간 기준 + 반기 실적 입력 → 미이수 과태료 자동 | 반기 교육 마감 |
| 8_설비검사 | 안전검사·정기검사 주기 + 대장(차기 예정일·D-day 자동) | 검사 신청 시점 관리 |
| 9_화학·PSM·LOTO | MSDS·경고표시·작업환경측정·특수건강진단·PSM·LOTO·안전인증 대상 | 업종 특화 법정업무 |
| 10_과태료기준표 | 시행령 별표35 개별기준(원문 기준 금액) + 일반기준(가중·감경) | 리스크 산정 근거 |
| 11_활용자료 | 지금까지 만든 자료 → 어느 서류에 쓰는지 연결 | 서류 작성 시 |
| 12_변경·확인필요 | 원자료와 다르게 적용한 부분, 확인 필요 사항 | 최종 확인 |
