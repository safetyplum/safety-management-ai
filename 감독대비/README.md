## 공통 시트
대시보드 · 서류점검표 · 연간달력 · 감독지적포인트 · 관리감독자 · 도급관리 · 교육관리 · 설비검사 · 과태료기준표(별표35) · 활용자료 · 변경·확인필요

## 사용법
1. `0_안내`에 사업장 정보(상시근로자 수 / 공사금액) 입력 → 과태료 감경률 자동
2. `2_서류점검표` 상태 입력(완비/보완필요/미비/해당없음)
3. `1_대시보드`에서 준비율·예상 과태료 확인 → 금액 큰 항목부터 보완
