## 핵심 근거 (출처)
- 고용노동부 「중대재해 사고백서 2025」 — 판결 71건(유죄 65·무죄 6), 관리감독자 등 평가·관리 위반 53건
- 대구지방고용노동청 기소 송치 38건 분석 — 위험성평가 위반 92%, 안전보건관리책임자 등 업무수행 위반 81.5%
- 대구지방고용노동청 「관리감독자 중심 안전보건관리」 가이드(2024.4, 2024.10.10 본부 전국 안내)
- 대법원 2026.10.20. 선고 2026도7102(아리셀), 광주지법 2025.1.7. 선고 2023고단5641(생산팀장 산안법 행위자) 등

## 주의
- 관리감독자는 중대재해처벌법의 **직접 처벌 대상이 아님** — 산안법(행위자)·형법(업무상과실치사)으로 처벌됨을 구분해 설명
- 판례·사고 사례는 공개 판결·보도 내용만 사용 (사업장 자료 아님)
- 개별 사건 대응은 **법률 검토 필요**
