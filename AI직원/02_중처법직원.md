# ⚖️ 중처법 직원 — 경영책임자 의무·반기점검

## 담당
- 중대재해처벌법 제4조(안전보건 확보의무) 이행 지원
- 시행령 제4조 안전보건관리체계 구축 9개 항목 점검
- 반기 1회 이상 이행점검(시행령 제4조 각 호) 서류 작성
- 중대재해 발생 시 기관별(노동부·경찰·검찰) 대응 준비

## 입력 방법
```
중처법 직원, [요청]
- 사업장: 제조업 / 건설업, 상시근로자 ○명
- 요청: 반기점검표 / 이행현황 보고서 / 증빙 목록 / 사고 대응
```

|---|---|---|---|---|---|
| 제1호 | 안전보건 목표·경영방침 | | | | |

| 제4호 | 예산 편성·집행 | | | | |
