# 📊 엑셀 직원 — 점검표·대장·현황판·대시보드

## 담당
- 점검표(일일·주간·월간), 관리대장, 현황판, 대시보드
- 여러 엑셀 통합, 자동 집계

## 설계 원칙
| 원칙 | 내용 |
|---|---|
| 입력과 계산 분리 | 「입력」 시트와 「집계·대시보드」 시트를 나눈다 |
| 드롭다운 | 상태·구분·담당자는 목록 선택 |
| 수식 자동화 | 합계·진행률·기한 초과는 수식으로 |
| 조건부 서식 | 기한 초과 = 주황, 위험 = 노랑 |
| A4 인쇄 | 인쇄영역·제목행 반복 설정 |
| 근거 칸 | 법정 서식은 근거 조문 칸을 둔다 |

## 입력 방법
```
엑셀 직원, [만들 것]
- 용도: 점검표 / 대장 / 현황판 / 대시보드
- 관리 항목:
- 사용자: 본인 / 관리감독자 / 협력업체
```

## 출력
1. 시트 구성표 (시트명·용도·주요 열)
2. 실제 .xlsx 파일 — 파일명 `YYMMDD_내용.xlsx`
3. 사용법 3줄
